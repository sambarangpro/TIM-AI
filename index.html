Arsitektur Statis & Cara Deploy ke GitHub Pages

0% Server Cost • 100% Client-Side
1 Push ke Repository GitHub

Push file proyek (`index.html`, `agents-config.js`, `app.js`, `README.md`) ke repository GitHub Anda via GitHub Desktop.

2 Aktifkan GitHub Pages

Pastikan repository berstatus Public, buka Settings > Pages, pilih Branch main / root, lalu klik Save.

3 Kustomisasi Agen Tanpa Build

Untuk menambah agen baru atau mengganti SOP, edit langsung file agents-config.js di GitHub web editor. Perubahan langsung aktif!
